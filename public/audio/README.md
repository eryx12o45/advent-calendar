# Audio-Dateien für den Adventskalender

## Anleitung

Platzieren Sie Ihre Audio-Dateien (MP3-Format) in diesem Ordner mit folgender Namenskonvention:

- `day1.mp3` - für Türchen 1 (1. Dezember)
- `day2.mp3` - für Türchen 2 (2. Dezember)
- `day3.mp3` - für Türchen 3 (3. Dezember)
- ...
- `day24.mp3` - für Türchen 24 (24. Dezember)

## Beispiel-Struktur

```
audio/
├── day1.mp3
├── day2.mp3
├── day3.mp3
├── ...
├── day23.mp3
└── day24.mp3
```

## Hinweise

- Alle Dateien sollten im **MP3-Format** vorliegen
- Die Dateien werden automatisch geladen, wenn ein Türchen geöffnet wird
- Stellen Sie sicher, dass alle 24 Dateien vorhanden sind für ein vollständiges Erlebnis
- Empfohlene Audiodauer: 1-5 Minuten pro Datei

## Beispiel-Inhalte

Sie können folgende Arten von Audio-Inhalten verwenden:
- Weihnachtsmusik
- Weihnachtsgeschichten
- Gedichte
- Persönliche Nachrichten
- Podcast-Episoden
- Hörbuch-Ausschnitte
